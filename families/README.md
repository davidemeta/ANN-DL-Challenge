# families/

One folder per person/family, named `<letter>_<name>` (2026-27: `A_convnextv2`, `B_effnetv2`, `C_regnety`, `D_embeddings` — D owned by the lead).
Each contains `train.py`, a YAML config, and optionally one launcher notebook (use `nbstripout`).
Two people must not work on the same family. Output files follow the contract in docs section 1.4.
